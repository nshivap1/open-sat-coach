# ADR 0004 — No human review gates

Status: accepted (owner decision D-2) · Date: 2026-10-18

**Decision.** Content is approved by deterministic checks plus an independent AI review run.
- Failures are quarantined, never queued for a person.
- The student-facing label reads "checked by automated review".
- Students can report problems locally.

**Consequences.** Quality claims come only from published evaluation results. The README and About screen say there is no human expert review.
